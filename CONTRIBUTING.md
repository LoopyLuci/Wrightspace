# Contributing to WebBuilder

Thank you for your interest in contributing! This document outlines how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/WebBuilder.git`
3. Install dependencies: `pnpm install`
4. Create a branch: `git checkout -b feature/your-feature`

## Development Workflow

1. Make your changes
2. Run tests: `pnpm test`
3. Run linting: `pnpm lint`
4. Commit with clear messages: `git commit -m "feat: add new feature"`
5. Push to your fork: `git push origin feature/your-feature`
6. Open a Pull Request

## Code Standards

- TypeScript for all new code
- 2-space indentation
- Meaningful variable names
- Comments for complex logic
- Tests for new features

## Plugin Development

See [Plugin API Documentation](docs/plugins.md) for creating plugins.

## Code of Conduct

Be respectful, inclusive, and constructive.
